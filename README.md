# Math IO![logo_color.png](assets%2Flogo_color.png)
**Math IO** is an interactive streamlit platform that connects mathematics with artificial intelligence.  
It provides a simple web interface and API for performing operations on data, matrices, and images —  
powered by algorithms and models implemented in the [**Ai Box**](https://github.com/Piotrek-max/AIbox) project.

## Purpose
- Serve as a simple&practical interface to AI and mathematical methods  
- Demonstrate how mathematical operations power modern AI models  
- Visualize computations and results in an accessible way  
- Integrate directly with reusable algorithms from **AI Box**  



## Project setup
```sh
uv sync
```


## Usage
Run app:
```sh
streamlit run app.py
```

Extend capabilities:
Create your own tabs to personalize app usage.
